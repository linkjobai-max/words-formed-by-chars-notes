Find Words That Can Be Formed by Characters (LeetCode 1160): Count, Then Compare

You get a list of words and a string chars. A word is good if it can be built from chars, using each character at most once per word. Return the total length of all good words.

Frequency arrays

Count chars once into 26 slots. For each word, count its letters and check that no slot exceeds the budget. Because the budget is reused for every word, never mutate the original counts.

from collections import Counter

def countCharacters(words, chars):
    have = Counter(chars)
    total = 0
    for w in words:
        need = Counter(w)
        if all(have[ch] >= k for ch, k in need.items()):
            total += len(w)
    return total

Time is O(total letters across words plus len(chars)). Extra space is O(1) since the alphabet is fixed at 26.

Small wins worth mentioning

  • Skip a word immediately if it is longer than chars.
  • With plain lists of 26 ints you avoid hashing and can bail out on the first letter that runs short.
  • This is the same check as Ransom Note (LeetCode 383); saying so shows pattern recognition.
